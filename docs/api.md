# API reference

Interactive documentation (generated by FastAPI from the code, always up to date): **http://localhost:8000/docs**
Click **Authorize**, enter your email as `username` and your password, and every endpoint can be tried in the browser.

Base URL: `/api/v1`. All endpoints except `health`, `auth/register`, `auth/login`, `auth/refresh` require
`Authorization: Bearer <access_token>`. Errors are JSON: `{"detail": "message"}` (validation errors: a list of `{loc, msg}`).

## Health
| Method | Path | Description |
|---|---|---|
| GET | `/health` | `{status, database, database_latency_ms, ...}`; 503 when the database is down |

## Authentication
| Method | Path | Body | Notes |
|---|---|---|---|
| POST | `/auth/register` | `{email, full_name, password}` | 201 user; 409 email taken; 5/hour per IP |
| POST | `/auth/login` | form: `username`, `password` | `{access_token, token_type, expires_in, user}` + httpOnly `refresh_token` cookie; 10/min per IP |
| POST | `/auth/refresh` | cookie | New access token, rotated cookie; reuse of an old token revokes all sessions |
| POST | `/auth/logout` | cookie | 204, revokes the session |

## Users
| Method | Path | Body |
|---|---|---|
| GET | `/users/me` | – |
| PATCH | `/users/me` | `{full_name?, preferred_language?: "en"|"te"}` |
| POST | `/users/me/password` | `{current_password, new_password}` → other sessions logged out |
| DELETE | `/users/me` | `{password}` → deletes account, files, vectors, chats |

## Documents
| Method | Path | Description |
|---|---|---|
| POST | `/documents` | multipart `files` (≤10 PDFs, ≤25 MB each) → `{uploaded: [...], rejected: [{filename, reason}]}`; processing starts in the background |
| GET | `/documents` | list (status, progress, page/chunk counts, notes) |
| GET | `/documents/{id}` | one document |
| POST | `/documents/{id}/reprocess` | 202; 409 if already processing |
| DELETE | `/documents/{id}` | 204; removes file, extracted images, vectors |
| GET | `/documents/{id}/file` | the PDF (inline) |
| GET | `/documents/{id}/pages` | `[{page_number, extraction_method, char_count}]` |
| GET | `/documents/{id}/pages/{n}` | page text |
| GET | `/documents/{id}/pages/{n}/image?zoom=1.5` | page rendered as PNG |
| GET | `/documents/{id}/elements?element_type=&page=` | tables / images / figures |
| GET | `/documents/{id}/elements/{eid}/image` | extracted picture (PNG) |

## Search (retrieval only)
`POST /search` — `{query, mode: "hybrid"|"dense"|"keyword", rerank: true, top_k: 5, document_ids?: [..]}`
→ `{hits: [{chunk_id, document_id, document_title, page_number, element_type, text, score}], latency_ms}`

## Conversations
| Method | Path | Body |
|---|---|---|
| POST | `/conversations` | `{title?, document_ids?}` |
| GET | `/conversations` | – |
| GET | `/conversations/{id}` | – (messages with citations and claims) |
| PATCH | `/conversations/{id}` | `{title?, document_ids?}` |
| DELETE | `/conversations/{id}` | – |
| POST | `/conversations/{id}/messages` | `{content, answer_language: "auto"|"en"|"te", document_ids?}` → `{user_message, assistant_message}`; 20/min per user; 503 without API key; 502 on LLM errors |

Assistant message fields: `status` (`answered` / `insufficient_information`), `content`, `language`, `faithfulness_score`,
`claims[] {text, text_display, cited_numbers, verdict, confidence, evidence_number, evidence_snippet}`,
`citations[] {number, document_id, document_title, page_number, element_type, element_id, snippet, relevance_score}`,
`details {english_question, question_language, timings_ms, warnings}`.

## Example session (PowerShell)
```powershell
$base = "http://localhost:8000/api/v1"
Invoke-RestMethod "$base/auth/register" -Method Post -ContentType "application/json" `
  -Body '{"email":"me@example.com","full_name":"Me Test","password":"Passw0rd!"}'
$token = (Invoke-RestMethod "$base/auth/login" -Method Post -Body @{username="me@example.com"; password="Passw0rd!"}).access_token
$h = @{ Authorization = "Bearer $token" }
Invoke-RestMethod "$base/documents" -Headers $h
Invoke-RestMethod "$base/search" -Method Post -Headers $h -ContentType "application/json" -Body '{"query":"What is attention?"}'
```
